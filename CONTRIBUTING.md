# Contributing to WebPerceptor

Thank you for your interest in contributing! 

All contributions are welcome, whether it's bug fixes, new features, documentation updates, or other improvements. 

By following this guide, you help maintain somewhat organised development process. 

Note: this is version 1.0 of a contribution statement. Depending on how things go this is likely to change over time so make sure you read the latest version if you are interested in contributing. 


## How to Contribute

1. **Fork the repository** to your own GitHub account.  

2. **Create a new branch** for your changes:
   ```bash
   git checkout -b my-feature
   ```

3. Make your changes locally and commit them.

4. Push your branch to your fork:
	```bash
	git push origin my-feature
	```
5. Open a Pull Request (PR) to the main branch of this repo.

6. Wait for review. Address any feedback and resolve all conversations.

7. Once approved, your PR will be merged into main.


## Commit Guidelines
- Write clear, concise commit messages describing what your change does
- Keep commits small and focused
- Sign your commits


## Issues

When opening an issue please try to provide:
- A clear description of the problem or request
- Steps to reproduce (for bugs)
- Expected behavior vs actual behavior
- Any relevant screenshots, logs, or environment information
- Descriptive titles to help stay organised 


## Feature Requests
- Open a new issue labeled feature request
- Include a description of the feature, why it is needed, and any examples or use cases
- Discuss in the issue before submitting a PR for implementation


## Code of Conduct
By contributing, you agree to follow the project's Code of Conduct to maintain a friendly, safe, and collaborative environment
